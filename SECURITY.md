# Security

This tap only points Homebrew at the releases of [immich-apple-silicon](https://github.com/epheterson/immich-apple-silicon): a formula and a cask, each with the checksum of a release asset. A report about the formula or cask belongs here; a report about the software itself belongs in that repository's [advisory form](https://github.com/epheterson/immich-apple-silicon/security/advisories/new).

## Reporting a vulnerability

Report it privately through GitHub: **[Security > Report a vulnerability](https://github.com/epheterson/homebrew-immich-accelerator/security/advisories/new)**. Please do not open a public issue, discussion or pull request for it.

Include what you found, how to reproduce it, and what an attacker could reach with it. You will get an answer as soon as I can, and credit in the advisory unless you would rather not.

## Supported versions

The latest formula and cask, which the release workflow in immich-apple-silicon rewrites on every release.
